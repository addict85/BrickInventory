Preisalarme

Alle Schwellen, die du gesetzt hast. Der Wert lässt sich hier ändern, der Alarm entfernen. Gemeldet wird einmal je Übergang — erst wenn der Preis wieder auf die andere Seite wechselt, kann derselbe Alarm erneut auslösen.

Lagerorte

Die Orte, die beim Set und beim Teil zur Auswahl stehen. Neue Orte lassen sich auch direkt dort eintragen; hier kannst du sie umbenennen oder entfernen.

Haushalt

Verknüpfe Konten zu einem Haushalt: Ein Hauptkonto sieht die Sets, Teile und Minifiguren seiner direkten Unterkonten zusammengefasst. Ein Konto kann zu mehreren Hauptkonten gehören, wenn es jede Einladung selbst annimmt. Beide Konten müssen dieselbe Währung verwenden.
Konto einladen
Erzeuge einen Einladungscode und gib ihn im anderen Konto unter Einstellungen ein. Der Code ist 24 Stunden gültig und nur einmal verwendbar.
Einladung annehmen
Gib den Code aus dem Hauptkonto ein. Dieses Konto wird danach im Hauptkonto mit angezeigt; deine Daten bleiben deine.

Willkommen — BrickInventory einrichten

Das Startpasswort stand nur im Protokoll des Servers. Bitte jetzt ein eigenes setzen.

Ohne diese Schlüssel bleibt die Sammlung leer: Rebrickable liefert Sets, Teile und Bilder, BrickLink die Preise, Brickset Anleitungen. Alle drei sind kostenlos; Rebrickable ist das Wichtigste.

Rebrickable
Wo bekomme ich den Schlüssel? rebrickable.com → API → Generate Key
BrickLink
Wo bekomme ich die Schlüssel? bricklink.com → API-Zugang registrieren (vier Werte)
Brickset
Wo bekomme ich den Schlüssel? brickset.com → Tools → API-Schlüssel anfordern
