# Beide beschreiben Entscheidungen, die in res/xml/network_security_config.xml
# ausfuehrlich begruendet sind:
#
#   * cleartextTrafficPermitted="true" in der base-config, weil die Server-URL
#     der Nutzer selbst eintraegt — typischerweise eine private LAN-Adresse, und
#     RFC1918-Bereiche lassen sich in <domain> nicht per Wildcard ausdruecken.
#     Eingeschraenkt wird eine Ebene hoeher, im OkHttp-Abfanger
#     (util/NetworkPolicy.kt): Klartext nur zu privaten Adressen.
#   * <certificates src="user" />, damit ein selbst ausgestelltes Zertifikat
#     funktioniert. GitHub ist davon per domain-config ausgenommen (nur system),
#     weil von dort das APK kommt.
#

# unsichtbar, und das ist derselbe Fehler wie eine lint-Baseline: Man sieht
